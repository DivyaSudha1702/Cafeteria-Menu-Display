# 🍽️ Cafeteria Menu Display Portal (ServiceNow Project)

## 📌 Project Overview

The **Cafeteria Menu Display Portal** is a ServiceNow-based solution that streamlines the **creation, scheduling, and publication** of cafeteria menus across an organization.

It allows administrators to manage menus efficiently while providing employees with **easy access** to daily and weekly meal options.

## 🎯 Objectives

- Centralized platform for cafeteria menu management
- Simplify menu creation and publication
- Support organized menu scheduling
- Minimize manual effort and errors in menu handling
- Improve employee access to cafeteria menu information

## ⚙️ Features Implemented

1. **Studio Setup** – Created the Cafeteria Menu Display application using ServiceNow Studio.
2. **Table Design** – Added fields such as Menu Name, Date, Items, and Status.
3. **Service Catalog** – Employees can submit new menus through catalog items.
4. **Reports** – Generate cafeteria reports grouped by date and items.
5. **UI Actions** – Added a "Mark as Published" button to update menu status.
6. **Testing** – Validated Service Catalog submissions and UI Actions.

## 🛠️ Tech Stack

- **Platform:** ServiceNow
- **Modules Used:** Studio, Tables, Service Catalog, Reports, UI Actions

## 🚀 How to Use

1. Import the **Cafeteria Menu Display** Update Set XML into your ServiceNow instance.
2. Preview and commit the Update Set.
3. Open the Cafeteria Menu Display application.
4. Explore the custom table and its fields.
5. Use the Service Catalog item to submit menu details.
6. View cafeteria menu reports.
7. Test the UI Action such as *Mark as Published*.
